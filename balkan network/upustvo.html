Pratite jednostavne korake u nastavku kako biste se pridružili našoj zajednici.

PC (Java Edition)

  1. Pokrenite vaš Minecraft launcher i uđite u verziju 1.16 - 1.20+.
  2. U glavnom meniju kliknite na Multiplayer.
  3. Kliknite na dugme Add Server na dnu ekrana.
  4. U polje Server Address unesite IP: playbalkan.net
  5. Spremite klikom na Done i kliknite Join Server!

Telefon / Bedrock

  1. Otvorite Minecraft na vašem telefonu ili uređaju.
  2. Kliknite na Play, a zatim izaberite karticu Servers.
  3. Skrolujte na dno i kliknite na Add Server.
  4. Unesite Server IP: playbalkan.net
  5. Unesite Port: 19132 (Default) i kliknite Play!

Prvi ulazak na server? (Registracija)

Kada se prvi put povežete na server, potrebno je da registrujete vaš nalog komandom:
/register <vasa_sifra> <ponovite_sifru> (npr. /register mojasifra123 mojasifra123)

Svaki sledeći put kada ulazite na server, prijavljujete se komandom:
/login <vasa_sifra> (npr. /login mojasifra123)
